# Blueprints

Canonical Factory Shelf layer for reusable application architectures composed from admitted Modules
and/or Blocks. A Blueprint must define APP_PROFILE defaults, required permanent roles and skill
packs, quality policy, supported stack/integrations, deployment expectations and extension points.

No Blueprint is currently defined or admitted. Family OS, Business OS, Tutor and AI Kiosk remain
concepts until repository provenance and trusted exact-candidate evidence exist. Phase 6 does not
manufacture a Blueprint from a roadmap label, and Michel OS remains untouched until Phase 7.

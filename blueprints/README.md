# Blueprints

Canonical Factory Shelf layer for reusable application architectures composed from admitted Modules
and/or Blocks. A Blueprint must define APP_PROFILE defaults, required permanent roles and skill
packs, quality policy, supported stack/integrations, deployment expectations and extension points.

## Candidate blueprints

- `commerce-agentic/` — candidate v0.1.0 architecture for customer shopping assistance and merchant
  operations. It is an architecture-pattern study grounded in Anthropic's public
  `anthropics/commerce-agents` repository at exact commit
  `fd4d59224ab96b43c6dc6888207c67b3bd5a24cf`. No upstream implementation code is imported. The
  candidate is not admitted, is not eligible for normal production reuse, does not create a new
  permanent Factory role and does not authorize a Shia Baby deployment.

No Blueprint is currently **admitted**. Family OS, Business OS, Tutor and AI Kiosk remain concepts
until repository provenance and trusted exact-candidate evidence exist. Phase 6 does not manufacture
a Blueprint from a roadmap label, and Michel OS remains governed by the active Phase 7 lifecycle.

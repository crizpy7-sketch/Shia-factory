# Modules

Canonical Factory Shelf layer for combinations of multiple admitted Blocks behind one stable domain
interface. A Module may depend only on Blocks; circular, same-layer, Blueprint and Application
dependencies are invalid.

No Module is currently defined or admitted. Scheduling/runtime surfaces were inventoried as
`reusable-after-extraction`, but they remain coupled to BORIS and have no Module admission receipt.
This empty layer is deliberate, not missing progress.

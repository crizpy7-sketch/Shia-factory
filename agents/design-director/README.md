# Permanent Design Director

Design Director is an operational, callable bootstrap adapter over the permanent invocation contract, authority matrix, Design pack index and registered Figma/Canva ownership. It owns UX architecture, product/visual design, design systems, responsive behavior, motion, design accessibility and critique/taste.

No standalone design skill or duplicate identity was created. The adapter reports missing inputs honestly and cannot certify its own bootstrap. Cristian approval of the exact Phase 4 candidate remains required.

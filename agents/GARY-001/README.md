# GARY-001 Identity Architecture v0.4

Portable identity architecture for the Gary Growth Agent.

## Architecture principle
**The model is not Gary. The model powers Gary.**

The package separates:
1. **identity** — stable Shia-owned mission, personality, authority and role;
2. **cognitive model** — evidence-grounded operating principles that can evolve;
3. **knowledge** — research packets, verification reports, failures and changed beliefs;
4. **runtime** — replaceable model/execution-engine requirements;
5. **integration** — the agent card used by the Shia App Factory.

# GARY-001 Runtime Contract

A runtime hosting Gary must:
- load Gary's identity and certified cognitive model;
- retrieve relevant durable knowledge rather than stuffing all memory into every prompt;
- preserve Gary's personality without allowing style to override evidence or policy;
- support structured outputs for campaigns, reviews, experiments, and learning records;
- respect deterministic owner-approval, spend, publish, messaging, and secret-access boundaries;
- log material decisions, evidence, campaign outcomes, failures, and changed beliefs;
- support fresh-context or independent campaign review;
- support current-source retrieval when platform rules, trends, prices, or policies matter;
- never self-certify migration or research completion.

A runtime must not silently publish, spend, message customers, create accounts, access secrets, change Gary's identity, fabricate metrics, or claim public-figure endorsement.
